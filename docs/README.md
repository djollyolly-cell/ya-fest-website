## Operating layer

[docs/operating-system/](operating-system/) is the active operating layer for Ya-Fest project work. It is where current status, architecture contracts, roadmap, QA, handoffs, reviews, prompts, logs, and decisions are coordinated.

## Source and evidence material

Older PRD, spec, audit, campaign, source, and research documents remain valuable as evidence and source material. They are not proof that work has been completed. A plan, audit, or spec only becomes completed work when the code, files, tests, deploy checks, or current-state documents confirm it.

If older source material conflicts with [01-current-state](operating-system/01-current-state/README.md), current-state wins for implementation status. If code/tests conflict with docs, code/tests win and docs must be updated.
