# sources/

Здесь лежат шаблоны и заполненные протоколы победителей архивных
фестивалей Я-Фест. Формат заполнения — единый, чтобы после получения
данных от продюсера можно было в один pass:

1. Добавить блок «Итоги фестиваля» с именами в HTML.
2. Расширить `FAQPage` JSON-LD ответом «Кто победил?» со ссылкой на источник.
3. Добавить `Award` / `awardOfCategory` в `Event` JSON-LD с `awardWinner`
   per nomination.
4. Убрать anti-hallucination блок и снять gap в
   `yafest-entity-registry.md` и `05-brand-geo-content/STATE.md`.

## Правила

- Файл считается «заполненным», если в блоке «Источник» есть **хотя бы
  один** канонический URL или файл. Без него на сайт ничего не идёт.
- Заполненные версии называть с суффиксом `-filled.md`, чтобы шаблон
  оставался неизменным.
- Незаполненные строки таблиц — не пусто, а `Не присуждался`.
- Спецпризы, не заложенные в шаблон, писать в блок «Комментарии
  продюсера» с пометкой, публикуется ли это на сайте.
