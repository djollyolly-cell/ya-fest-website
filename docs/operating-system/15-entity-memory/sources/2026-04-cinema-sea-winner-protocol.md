# Протокол победителей — «Кино у моря» 2026

## Инструкция для заполнения (продюсеру)

1. Заполнить блок «Источник» — минимум **один** канонический URL или файл.
   Без источника имена не публикуются на сайте.
2. В таблицах заполнить только те строки, где приз действительно был вручён.
   Если никого не было — написать `Не присуждался`, не оставлять пусто.
3. «Победитель» = название фильма + режиссёр + город/студия. Для актёрских
   номинаций — ФИО актёра + название фильма.
4. Для игровых фильмов работает возрастная разбивка: младшая (до 11),
   средняя (12–16), старшая (от 17), смешанная (без ограничений). Заполнять
   отдельной строкой на возрастную группу.
5. Спецприз «Кинозабег» вручается за фильм, снятый во время фестиваля —
   отдельная секция ниже.
6. Готовый файл прислать в чат либо положить рядом с этим шаблоном под
   именем `2026-04-cinema-sea-winner-protocol-filled.md`.
