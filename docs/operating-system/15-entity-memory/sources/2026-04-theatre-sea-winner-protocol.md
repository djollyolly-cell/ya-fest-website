# Протокол победителей — «Театр у моря» (фестивальная серия «Театр и кино моря»)

## Инструкция для заполнения (продюсеру)

1. Заполнить блок «Источник» — минимум **один** канонический URL или файл.
   Без источника имена не публикуются на сайте.
2. Формат протокола — плоский список наград по степеням (не по конкурсным
   направлениям). На одну степень может приходиться несколько лауреатов.
3. «Победитель» = коллектив (или ФИО), город, спектакль. Если спектакль
   отсутствует в оригинальном протоколе — оставить пусто и явно отметить
   `спектакль в исходнике не указан`.
4. Если по какой-то степени наград не было — написать `Не присуждалось`.
5. Готовый файл сохранить с суффиксом `-filled.md`.
