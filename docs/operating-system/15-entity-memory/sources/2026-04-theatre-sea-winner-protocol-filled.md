## Примечания к структуре протокола

- Протокол не разделяет награды по конкурсным направлениям (драматический
  спектакль / заявка на будущий спектакль / музыкально-литературная
  композиция / художественное слово). Все победители перечислены плоским
  списком по степеням.
- В исходном протоколе не указан спектакль у одного из Лауреатов I степени
  («Переделкино», Москва) — это подтверждено, не опечатка.
- Протокол называется «Всероссийский театральный фестиваль “Театр и кино
  моря”», единой фестивальной серией. На сайте эта серия исторически
  разведена на две страницы (`theatre-sea.html` и `cinema-sea.html`).
  Кино-номинаций и «Кинозабега» в протоколе нет — нужно уточнение по
  отдельному кино-протоколу.
