# Agent Runtime Handoff

When leaving work in this area, record:

- branch, commit, or PR if applicable;
- changed files and changed operating areas;
- what was implemented versus what remains skeleton or planned;
- verification commands and results;
- checks that were not run and why;
- risks and compatibility notes;
- open questions;
- what the next worker must not repeat;
- deploy status using exact wording.

## Deploy status wording

Use one of these precise statements:

- No deploy was performed.
- runtime-contract deploy was performed for the named surface.
- staging product deploy was performed and checked for the named surface.
- production deploy was performed and checked for the named surface.
